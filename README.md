# Vô Ưu Tự

Ngôi chùa trực tuyến để thư giãn tâm hồn, trút bớt ưu phiền. Không liên kết hay quảng bá cho bất kỳ ngôi chùa nào.

- `site/` — website tĩnh, Netlify xuất bản thư mục này (xem `netlify.toml`).
- `server/Code.gs` — mã Google Apps Script (dán vào Apps Script của Google Sheet, không chạy trên Netlify).
- `server/HUONG-DAN.txt` — hướng dẫn triển khai và vận hành.
